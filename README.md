# Urban Sniper

Urban Sniper is a fast-paced first-person shooter (FPS) game that combines intense combat with unique wall-running mechanics. Players can navigate urban environments by wall-running, allowing for quick traversal and strategic positioning. The game features a variety of weapons, including pistols, rifles, and snipers, each with distinct attributes such as damage, fire rate, and range. With multiple levels, multiplayer modes, and a progression system, Urban Sniper offers a rich and engaging gaming experience.

## Install

1. Clone the repository: `git clone https://github.com/yourusername/urban-sniper.git`
2. Navigate to the project directory: `cd urban-sniper`
3. Install the required dependencies: `love .`

## Use

1. Run the game: `love .`
2. Use the WASD keys to move.
3. Press the spacebar to jump.
4. Hold the shift key to wall-run.
5. Use the mouse to aim and left-click to shoot.
6. Press R to reload your current weapon.
